Modes

      
    
        
  • meter-and-bill: crawlers in data-licensed are served and billed per token; every other AI crawler is blocked and its attempt is invoiced.
    • 
        
  • block: every AI crawler gets the 402 licence notice.
    • 
        
  • allow: every AI crawler is served and metered.
    • 
      

      
Unidentified headless clients are logged as Pending until you classify them.

      
Policy files

      
robots.txt disallows about 30 AI crawlers while keeping search engines and the policy files reachable. ai.txt and llms.txt state the licence terms in plain language for AI systems. tdmrep.json declares the EU text-and-data-mining reservation. Open any of them from the install section.

      
Edge enforcement

      
edge/worker.js is a Cloudflare Worker that runs in front of your origin:

      
    
        
  • Unlicensed AI crawler → 402 Payment Required with the terms, logged as blocked.
    • 
        
  • Licensed crawler (valid Authorization: AICS-License <key>) → origin response with AICS-Tokens-Metered and AICS-Charge-USD headers, logged as billed.
    • 
        
  • Everyone else → origin response plus X-Robots-Tag: noai and TDM headers.
    • 
        
  • POST /aics/events ingests shield events; GET /aics/events returns them with the admin token.
    • 
      

      
cp edge/wrangler.toml.example edge/wrangler.toml
wrangler secret put AICS_LICENSE_KEYS   # from Dashboard → API Keys → Edge worker secret
wrangler secret put AICS_ADMIN_TOKEN
wrangler deploy

      
Licence keys

      
Issue one key per licensed crawler in API Keys. Revoking a key takes effect after you update the worker secret. The crawler sends the key on every request; the worker meters what it delivers.

Billing & payouts

      
    
        
  • Charge per event: tokens × rate. Your share: charge × share (80% Starter, 85% Pro and Enterprise).
    • 
        
  • Generate invoices once per period: one per AI vendor, with separate lines for licensed access and blocked attempts.
    • 
        
  • Invoices move Draft → Sent → Paid. Only paid invoices count toward your payout balance.
    • 
        
  • Payouts are scheduled for the 1st of the next month to the method set in Account.
    • 
      

      
JavaScript API

      
AICS.events()            // all tracked events
AICS.stats(list?)        // totals by status, bot and day
AICS.on(fn)              // subscribe to new events (same-origin tabs too)
AICS.simulate("GPTBot")  // log a test crawl
AICS.toCSV()             // event export
AICS.snippet({...})      // embed snippet for a config
AICS.detect(ua?)         // crawler match for a user agent

      
Limits

      
robots.txt, ai.txt and meta tags are signals that compliant crawlers follow. The shield script only sees crawlers that run JavaScript, so use the edge worker for enforcement. In this build, events, invoices and payouts are stored in your browser; connect an event endpoint in Account to collect them on a server.
